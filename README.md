* When starting with Machine Learning, one common and important question arises:

“Which supervised machine learning model performs best for a given dataset?”

This project is built to answer that exact question.

It provides a comparative framework where multiple supervised ML models are trained and evaluated on two preloaded datasets. Each dataset undergoes Exploratory Data Analysis (EDA) and Feature Engineering (FE) before model training.

The project allows:

1. Comparison of multiple ML models

2. Evaluation using performance metrics

3. Prediction on dynamic user input

* Objectives

1 Train multiple supervised ML models on the same datasets

2. Compare model performance using evaluation metrics

3. Understand how different models behave on identical data

4. Enable prediction using real-time user input

5. Help beginners choose the most suitable model for a given problem
